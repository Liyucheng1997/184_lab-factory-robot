# 智能工厂物流调度仿真

基于 Three.js 的离散事件 + 连续运动混合仿真：一座 60 m × 37.5 m 的机加工厂，
16 台辊筒式 AMR 在二维码导航网格上完成 **收货 → 立体库入库 → 产线叫料配送 → 机加工 → 成品下线 → 装车发运** 的完整物料闭环。

## 运行

```bash
npm install
npm run dev
```

## AMR 模型

- **外观**：1050 × 820 × 620 mm 辊筒顶升式 AMR，对角布置的激光安全扫描仪、环形 LED 状态灯带、急停按钮、端部翻转挡停、差速驱动轮 + 万向轮、尾部状态屏（编号 + 电量）、充电触点。
- **运动学**：梯形速度曲线（空载 1.8 m/s、负载 1.3 m/s，加减速度独立），二维码网格上直行，转弯须停车原地旋转。
- **交通管制**：按制动距离 + 车身半长动态前瞻预约格子，未获预约则平滑减速停在格心；车尾离开后才释放格子。
- **路径规划**：时间最优 A*（状态含朝向），代价 = 行驶时间 + 转向时间 + 他车占用惩罚 + 历史拥堵软惩罚。
- **防死锁**：阻塞超时绕行重规划；静止空闲车被请求让行；站台停靠点互斥，后到车辆在附近等待位排队；连续受阻时侧向避让脱困。
- **电池**：按速度/负载/移载计算放电，恒流-恒压两段充电；低电量完成当前任务后自动去充电，空闲时机会充电，充满车辆可被抢占桩位；充电中电量足够时可被调度打断接单。
- **安全**：安全防护场（警告区/保护区）随速度伸缩，并随机注入"保护区入侵"安全停车事件。

## 调度（WMS + FMS）

- **拉动式生产**：工位空闲即叫料，立体库按先进先出、结合堆垛机负载选择货位出库；收货车辆按库容控制到货节奏。
- **任务类型**：入库搬运（月台 → 入库口）、产线配送（出库口 → 工位）、成品下线（工位 → 发货月台，优先装满在位车辆）。
- **指派**：按优先级与等待时长排序，选择成本最低的车辆（空驶时间 + 电量惩罚 + 打断充电惩罚）。
- **KPI**：小时产出、累计发货、加工件数、平均任务周期、AMR 利用率、机床稼动率、立库库存、车队能耗、交通热力图（通行/拥堵）。

## 操作

| 操作 | 说明 |
| --- | --- |
| 左键拖拽 / 右键拖拽 / 滚轮 | 旋转 / 平移 / 缩放 |

| 顶栏视角 | 总览 / 立体库 / 加工区 / 月台 / 俯视 |
| 1× – 10× | 仿真倍速 |
| 空格 / Esc | 暂停 / 取消选中 |
| 底部图层 | 路径规划、格预约、安全场、热力图、墙体剖切 |

## 代码结构

```
src/
  config.js            布局与工艺参数（网格、立库、工位、码头、车队、电池）
  main.js              渲染器、相机视角、主循环（固定步长 1/30 s）、交互
  core/
    grid.js            导航网格：静态障碍、格预约、通行/等待统计
    astar.js           时间最优 A*（二叉堆，含朝向状态）
    proc.js            generator 协程：wait / tween / 梯形速度轴运动 / 并行
    batcher.js         静态几何按材质合并（降低 draw call）
    materials.js       共享 PBR 材质与程序化贴图
  world/
    building.js        厂房、地坪、墙体剖切、钢结构、中控室、充电桩
    asrs.js            立体货架、堆垛机、出入库站台、库存
    workcell.js        加工中心 + 六轴机器人工艺流程
    arm.js             六轴机器人模型与逆运动学
    conveyor.js        辊道输送线、积放式站台
    docks.js           月台与半挂车
    load.js            托盘单元（托盘 + 工装 + 工件）
  fleet/
    amrModel.js        AMR 外观模型
    robot.js           AMR 控制器（运动、预约、移载、电池）
  wms/
    fleetManager.js    任务生成、指派、充电/泊车、让行、KPI
    events.js          仿真时钟、事件日志、计数器
  ui/
    hud.js             HMI 仪表盘
    heatmap.js         交通热力图
```

调试：控制台 `__sim.step(600)` 可快进 600 秒仿真，`__sim.fleet.kpi()` 查看 KPI。
