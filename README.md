# 工厂调度机器人仿真

基于 Three.js 的工厂仓库多机器人调度仿真：多台 AGV 搬运机器人在仓库中自动接单，
从货架取货并送往出货区，全程自主规划路径、动态避让其他机器人。

## 运行

```bash
npm install
npm run dev
```

打开 http://localhost:5173

## 功能

- **仓库场景**：货架区（4 组双排货架）、出货区（右侧绿色区域，带码头卷帘门）、
  充电待命区（左侧蓝色区域）、地面标线、顶部灯轨等。
- **任务调度**：调度中心自动/手动生成搬运任务（货架取货 → 出货点卸货），
  按距离最近原则分配给空闲机器人。
- **路径规划**：仓库离散为网格，A* 寻路（对被其他机器人占用的格子加惩罚成本，
  规划时倾向绕开交通拥挤路线）。
- **动态避障**：机器人驶入每一格前须先"占用"该格；被挡住时先等待，
  超时后把挡路格视为临时障碍重新规划绕行，自动化解对头/交叉冲突。
- **状态可视化**：每台机器人显示彩色路径线、头顶编号、状态灯
  （绿=空闲、蓝=执行任务、黄=装卸货、红=等待避让），左侧面板实时显示任务统计与机器人状态。

## 操作

| 操作 | 说明 |
| --- | --- |
| 鼠标左键拖拽 | 旋转视角 |
| 鼠标右键拖拽 | 平移 |
| 滚轮 | 缩放 |
| 空格 / 暂停按钮 | 暂停仿真 |
| ＋生成任务 | 立即追加 3 个搬运任务 |
| 速度滑块 | 0.5×–3× 仿真速度 |

## 代码结构

```
src/
  main.js        入口：渲染器、相机、UI、主循环
  warehouse.js   仓库场景构建（货架/围墙/地面标线/灯光）与布局数据
  grid.js        网格模型：静态障碍 + 动态格子占用（机器人互斥）
  astar.js       A* 寻路
  robot.js       AGV 机器人：状态机、移动、避让、装卸货动画
  dispatcher.js  任务调度：生成任务、就近分配、送达货物管理
```
